# CodeAlpha_EDA
Exploratory Data Analysis on Student Performance Dataset
## Power BI Dashboard
This dashboard was created using the StudentsPerformance dataset.
### Visualizations Included
- Average Math Score by Gender
- Average Math Score Card
- Average Reading Score Card
- Average Writing Score Card
- Students by Lunch
- Students by Test Preparation
### Tools Used
- Power BI Desktop
- Python
- Jupyter Notebook
